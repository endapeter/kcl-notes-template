# Personal LaTeX Template for in-class Lecture Note-Taking

This is a LaTeX template I created to standardize my LaTeX note-taking in class. Some quality of life defintions and customized formatting is included. Includes custom formatting of `\keypoint{}` and `\examptip{}` commands.
